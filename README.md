# Platform SDK Public Review Mirror

This repository is a public sanitized review mirror for ChatGPT review.

Private source of truth remains in the private repository:

- Private repo: git@github.com:i-wendao/platform-sdk-ingestion.git
- Public repo: git@github.com:i-wendao/platform-sdk-review-public.git

No secrets, tokens, raw data, database dumps, runtime credentials, private keys, or real platform API evidence are allowed here.

Public review materials are exported by whitelist only.

This repository must not be merged back into the private repository.
