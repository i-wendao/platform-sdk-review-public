# Before / After

## Before

V7 already treated historical governance files as subordinate and required explicit approval for risky actions, but it did not explicitly define external workflow watch sources as watch-only references.

## After

V7 now explicitly says:

- external AI workflow / governance sources are watch-only references
- they are not project authority
- adoption requires a separate batch, explicit approval, public-safe review, and ChatGPT review
- they must not be auto-copied into V7
- they must stay outside the main source tree and not be executed
