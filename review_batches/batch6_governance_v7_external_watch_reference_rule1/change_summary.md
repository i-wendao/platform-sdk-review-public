# Change Summary

This batch adds a minimal V7 rule for external AI workflow / governance watch sources.

## Updated file

- `docs/GOVERNANCE_V7.md`

## Rule added

- external watch sources are watch-only references, not authority
- any adoption must happen in a separate batch with explicit approval and public-safe review
- external sources must not be copied automatically into V7
- external repositories must remain outside the main source tree and not be executed
