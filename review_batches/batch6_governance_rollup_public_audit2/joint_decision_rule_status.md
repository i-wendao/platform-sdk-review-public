# Joint Decision Rule Status

The external watch joint decision rule is active in V7.

Key points:

- Codex must not independently decide whether an external watch source becomes authority
- Codex must not independently decide whether external-source content should be cited, absorbed, or used to revise V7 / project rules
- Codex may only produce public-safe snapshots, summaries, candidate practices, and risk notes
- final adoption / citation / absorption / revision decisions require joint user + ChatGPT approval

This preserves the separation between observation and authority.
