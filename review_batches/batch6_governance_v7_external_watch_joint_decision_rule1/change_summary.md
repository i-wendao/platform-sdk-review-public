# Change Summary

This batch adds a joint-decision rule for external watch sources to V7.

## Updated file

- `docs/GOVERNANCE_V7.md`

## Rule added

- Codex cannot independently decide whether an external watch source becomes authority
- Codex cannot independently decide whether to cite, absorb, or revise V7 / project rules based on external sources
- Codex may only produce public-safe snapshots, summaries, candidate practices, and risk notes
- final adoption/revision decisions require joint user + ChatGPT approval
