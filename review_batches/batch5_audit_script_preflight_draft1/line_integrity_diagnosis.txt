- Local private script, private review snapshot, and local public mirror snapshot were compared byte-for-byte.

- If GitHub web raw still displays a compressed first line while local public mirror bytes are correct, the mismatch is outside the local generation/copy/export path captured here and should be checked against the exact GitHub URL/cache/view used for review.
- No CR-only newline pattern or literal backslash-n encoding should be accepted as a valid script format.
