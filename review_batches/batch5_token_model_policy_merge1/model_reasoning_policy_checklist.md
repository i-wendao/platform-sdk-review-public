# Model Reasoning Policy Checklist

- single source of truth: covered by `Model and reasoning level policy`.
- one batch / one model / one reasoning level: covered.
- model and reasoning by highest batch risk: covered.
- required checks follow current batch model: covered.
- low model stop rule: covered.
- token saving cannot override governance: covered.
- no second policy source: covered; old model/reasoning policies are treated as merged into `TOKEN_EFFICIENCY_POLICY.md`.
