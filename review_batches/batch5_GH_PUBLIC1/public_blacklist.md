# Public Blacklist

以下内容必须禁止公开：

- `.env`
- `.env.*`，除非是已确认无敏感值的 `.env.example`
- private key
- `.pem`
- `.key`
- token
- secret
- access_token
- refresh_token
- runtime token
- database dump
- `.db`
- `.sqlite`
- raw / staging / ctrl / DWD / mart 真实数据
- API 返回原文 evidence
- 店铺真实 ID
- partner ID
- shop ID
- access token
- refresh token
- `node_modules/`
- package manager cache
- 供应商、订单、财务、客户、平台后台真实数据
- 任何从旧项目复制来的业务数据

如命中文件名或内容风险，必须停止公开导出，进入人工复核。
