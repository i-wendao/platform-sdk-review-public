# ChatGPT Review Cadence

1. Every 3-5 low/medium-risk batches, generate a governance checkpoint for ChatGPT review.
2. Before every Tier 3 high-risk batch, check open governance gaps.
3. Every stop, failure, rollback, or unexpected apply result must enter Issue Closed Loop audit.
4. Every new rule, directory, public/private sync strategy, or execution tier must trigger a PROJECT_MAP / DECISION_LOG update check.
5. Before public mirror sync, run path blacklist and high-confidence credential checks.
6. Before ChatGPT reviews a checkpoint, Codex must not claim the v6 governance loop is fully closed.
7. Public mirror links can reduce zip uploads only when content is explicitly sanitized and white-listed.
8. Zip/evidence packages remain required when public mirror cannot safely carry the material.
